# 🌿 AtzvaVote · הצבעת אצווה

מערכת דירוג אצוות פנים-ארגונית לחברת שיח, שנבנתה על התשתית של מערכת מונדיאל 2026.
**React + Node.js + MySQL 8** · עברית RTL (he/en/ar) · ערכות מיתוג מתחלפות.

## מה זה?

**רמה 1 — משחק האצוות (החברה):** כל עובד מדרג 1–5 את האצווה שנמצאת כרגע בתחנה שלו —
גידול, עיבוד, יישון, מפעל, שיווק או מכירות. הדירוג הוא ניחוש: כשתוצאות המכירה נכנסות,
המנהל מזין רמת הצלחה אמיתית (1–5 מול יעדים שנקבעו מראש). ניחוש מדויק = 5 נק', סטייה של
רמה אחת = 2 נק'. בסוף כל רבעון — כל האצוות שנמכרו מחלקות ציון, ומצטבר לוח מצטיינים רבעוני.

**רמה 2 — דירוג חיצוני:** דירוג מוצרים מקטלוג שיח (סנכרון מ-seach-data-api) לפי
השפעה, אחידות, משתלמות, צורת פרחים, ריח וטעם — רייטינג קהל כחלק מפונקציית האישור על מוצר.

**רמת התחרות — קרבות:** מוצר מול מוצר (למשל תכלת מול וודינג קייק) בכמה קטגוריות;
המנצח נקבע לפי הצבעת הרוב.

**נקודות ופרסים:** נקודות הדיוק ניתנות למימוש בחנות הפרסים (כובע 318 · חולצה 500 · תקליט 900),
בנוסף לכלכלת המטבעות ("שיחים") להימורי אצווה בין עובדים.

## ⚡ התחלה מהירה

נדרש: **Node.js 18+** ו-**MySQL 8**.

```bash
cp env.example server/.env      # לעדכן פרטי MySQL וסיסמת מנהל
npm install && npm run all      # מתקין הכל, יוצר DB, מאכלס, ומריץ
```

לאחר מכן: **http://localhost:5235** · התחברות עם `admin@company.local` / הסיסמה מה-.env.

> פורטים: שרת **5232** · לקוח (Vite dev) **5235** — שונים בכוונה ממונדיאל 2026 (5222/5225)
> כדי ששתי המערכות ירוצו על אותו שרת. פרודקשן: `atzvavote.canabolabs.com`.

## 📜 פקודות

```bash
npm run install:all        # התקנת root + server + client
npm run db:create          # יצירת DATABASE (atzvavote, utf8mb4)
npm run db:init            # יצירת טבלאות (idempotent)
npm run db:seed            # אצוות דמו, פרסים, לוז, תרגומים, מנהל
npm run db:setup           # שלושתם ברצף
npm run db:reset           # ⚠️ DROP + הקמה מחדש (פיתוח בלבד)
npm run dev                # שרת + לקוח במקביל
npm run prod               # build לקוח + שרת יחיד שמגיש הכל
```

## 🗂️ קונפיגורציה עיקרית (`server/.env`)

ראה `env.example`. שדות חשובים: `PORT=5232`, פרטי MySQL (`DB_NAME=atzvavote`),
`SEACH_API_URL` + `SEACH_API_KEY` לסנכרון קטלוג המוצרים (רמה 2), `THEME=seach`
לערכת המיתוג (מתוך `resources/themes/`).

## 🧭 ארכיטקטורה

- `server/` — Express + MySQL: `schema.js` (טבלאות), `services/scoring.js` (מנוע ניקוד הדיוק),
  `routes/` (batches, ratings, products, battles, prizes, coin-bets, guess-groups, reviews, admin...).
- `client/` — React 18 + Vite: עמודי דירוג (Rate), לוח אצוות, מוצרים, קרבות, חנות פרסים,
  לוח מצטיינים רבעוני, ופאנל ניהול מלא.
- `resources/themes/` — ערכות מיתוג (לוגו/צבעים/רקעים) המוחלפות ב-`THEME=` — התשתית
  לשלב ה-THEMES הבא (נושאי תוכן מתחלפים: קנאביס היום, מערכת בחירות בהמשך).
